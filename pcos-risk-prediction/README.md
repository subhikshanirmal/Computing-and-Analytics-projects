# PCOS Undiagnosed Risk Prediction and Risk Factor Analysis

## Project Overview

This project focuses on developing machine learning models to predict potential PCOS risk and analysing associated risk factors using data analytics techniques.

The project applies statistical analysis, exploratory data analysis, and predictive modelling to examine patterns in the dataset, compare classification algorithms, and generate data-driven insights related to PCOS risk.

## Objectives

- Analyse the dataset to identify patterns and potential risk factors associated with PCOS.
- Perform data preprocessing and exploratory data analysis.
- Develop machine learning models for PCOS risk prediction.
- Compare model performance using appropriate evaluation metrics.
- Visualize analytical findings and model comparison results.

## Tools and Technologies

## Methodology

1. **Data Preprocessing:** Prepare the dataset for analysis and model development.
2. **Exploratory Data Analysis:** Examine data distributions, patterns, and relationships between variables.
3. **Risk Factor Analysis:** Analyse variables associated with PCOS risk.
4. **Model Development:** Implement Logistic Regression, Random Forest, and XGBoost classification models.
5. **Model Comparison:** Evaluate and compare the developed models using classification performance metrics.
6. **Visualization:** Present analytical findings and model comparison results through visualizations.

## Machine Learning Models

- Logistic Regression
- Random Forest Classifier
- XGBoost Classifier

## Model Evaluation

The models are evaluated using classification metrics, including:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

Model comparison results are provided in the project files.

## Limitations

- Model performance depends on the quality and representativeness of the available dataset.

## Disclaimer

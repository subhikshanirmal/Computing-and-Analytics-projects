# Computer Security Controls Against Cybersecurity Threats

## Project Overview

This project examines computer security controls and their role in protecting information systems against cybersecurity threats. It focuses on identifying security risks and analysing preventive, detective, and corrective controls used to protect system resources, maintain data confidentiality, and improve organizational security.

## Objectives

- Understand common cybersecurity threats and vulnerabilities.
- Examine the importance of information security controls.
- Analyse preventive, detective, and corrective security mechanisms.
- Study access control and authentication practices.
- Understand security monitoring and incident detection.
- Explore security strategies for protecting information systems.

## Domain

Cybersecurity and Information Security

## Security Concepts

- Confidentiality, Integrity, and Availability (CIA Triad)
- Cybersecurity Threat Analysis
- Vulnerability Management
- Risk Assessment
- Defense in Depth

## Security Controls Analysed

### 1. Preventive Controls
Security mechanisms designed to prevent unauthorized access and security incidents.

### 2. Detective Controls
Mechanisms used to identify suspicious activities, security violations, and potential threats.

### 3. Corrective Controls
Measures implemented to recover from security incidents and reduce their impact.

### 4. Access Control
Controls governing user permissions and access to system resources.

### 5. Authentication
Security mechanisms used to verify user identities.

### 6. Security Monitoring
Monitoring activities used to identify suspicious behaviour and potential security incidents.

## Technical Methodology

1. Identify common cybersecurity threats and security risks.
2. Examine security principles and protection requirements.
3. Study preventive, detective, and corrective controls.
4. Analyse access control and authentication mechanisms.
5. Evaluate the role of security monitoring.
6. Review security practices for reducing organizational risk.

## Reference Frameworks and Standards

## Key Outcomes

- Developed an understanding of cybersecurity threats and security risks.
- Examined different categories of computer security controls.
- Analysed access control, authentication, and monitoring practices.
- Studied security mechanisms for protecting information systems.
- Explored the importance of layered security and risk mitigation.

## Project Significance

This project demonstrates an understanding of computer security principles, cybersecurity risk management, and organizational security controls. It provides a foundation for analysing information security practices and evaluating mechanisms used to protect digital assets.

## Limitations

- The study is based on research and analysis rather than a live security deployment.
- Security effectiveness depends on organizational requirements and implementation.
- Cybersecurity threats continuously evolve, requiring regular security assessments.

# CRUD Operations in Student Database Using SQL

## Project Overview

This project focuses on implementing Create, Read, Update, and Delete (CRUD) operations on a student database using SQL. It demonstrates fundamental database management operations for inserting, retrieving, modifying, and deleting student records within a structured relational database.

## Objectives

- Implement CRUD operations using SQL queries.
- Create and manage student database records.
- Retrieve student information using SQL SELECT statements.
- Modify existing student records.
- Delete student records from the database.
- Understand fundamental relational database operations.

## Tools and Technologies

| Category | Technologies |
|---|---|
| Database Language | SQL |
| Database Concepts | Relational Database Management |
| Core Operations | CRUD |
| Data Management | SQL Queries |

## Technical Implementation

### 1. Create (INSERT)
Insert new student records into the database using SQL INSERT statements.

### 2. Read (SELECT)
Retrieve student information using SELECT queries.

### 3. Update (UPDATE)
Modify existing student details using SQL UPDATE statements.

### 4. Delete (DELETE)
Remove student records from the database using SQL DELETE statements.

## Key Operations

- Student record insertion
- Student data retrieval
- Student information modification
- Student record deletion
- SQL query execution

## Key Outcomes

- Implemented all four fundamental CRUD operations.
- Applied SQL queries for student record management.
- Gained practical experience in relational database operations.
- Developed an understanding of structured data manipulation.

## Project Significance

This project demonstrates practical SQL skills and an understanding of database manipulation through CRUD operations. It establishes a foundation in relational database management and structured data processing.

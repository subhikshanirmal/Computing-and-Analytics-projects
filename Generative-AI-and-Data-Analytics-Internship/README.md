# Generative AI, Machine Learning and Data Analytics Internship

## Project Overview

This repository documents practical technical work carried out during a Generative AI and Data Analytics internship. The work involved exploring Generative AI technologies, developing machine learning models, performing exploratory data analysis, creating analytical dashboards, and supporting Agile project coordination.

The internship provided hands-on exposure to AI-driven applications, predictive modelling, business intelligence, and data-driven decision-making.

## Objectives

- Explore Generative AI technologies and large language model applications.
- Apply prompt engineering and workflow automation techniques.
- Perform exploratory data analysis and develop analytical dashboards.
- Develop and evaluate classification and regression models.
- Apply data preprocessing and feature engineering techniques.
- Support Agile project coordination and collaborative development.
- Communicate analytical findings and project progress to stakeholders.
